# Акции Мосбиржи — дашборд и калькулятор

Страница: https://ileyka-a11y.github.io/moex-dashboard/

- При открытии страница берёт цены прямо с ISS Мосбиржи (задержка ~15 мин); если не получилось — показывает последний автоснимок.
- Автоснимки по будням в 10:05, 13:05, 16:05, 19:05, 22:05 МСК (`.github/workflows/snapshot.yml`) сохраняются в `data/`.
- Дивиденды обновляются раз в день с smart-lab.ru (`scripts/dividends.py`).
- Базовые данные (закрытия 02–23.10.2026, сектора, лоты) — `data/base.json`.

Не является инвестиционной рекомендацией.
